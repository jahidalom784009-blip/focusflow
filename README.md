# FocusFlow — Personal Productivity PWA
Mobile-first daily planner with tasks, habit tracking, schedule, notes, goals, dark mode, local autosave, JSON backup/restore and offline app-shell caching.

## Publish on GitHub Pages
1. Create a public repository named `focusflow`.
2. Upload all files in this folder to the repository root (not just the ZIP).
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Open the HTTPS URL GitHub Pages provides.

All user data is stored in localStorage in the current browser and does not automatically sync between devices. Export JSON backups regularly.
